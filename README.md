# ByteRecorder portátil

Gravador de tela para Windows x64, criado pelo Canal M7 Dicas.

## Download

Abra a página de **Versões** e baixe `ByteRecorder-v2.0.0-Portable.exe`. Esse é o único arquivo necessário para executar o programa. Na primeira abertura, ele extrai os componentes para `%LOCALAPPDATA%\ByteRecorder\portable`.

O executável ainda não tem assinatura digital. O Windows pode mostrar um aviso de reputação. Confira a origem e o hash SHA-256 exibido na versão antes de executar.

## Recursos e estado da versão

O aplicativo permite escolher tela ou janela, microfone e áudio do PC, pasta de destino e saída MP4 ou MKV. Se a conversão falhar, preserva a gravação original em WebM.

O pacote e a conversão de um vídeo curto para MP4 e MKV com áudio foram verificados. A captura completa pela interface gráfica ainda não foi testada, por isso a versão está marcada como beta.
